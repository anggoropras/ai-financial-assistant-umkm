# Afin.ai — User Journey

## 1. User Persona

### Persona Utama
**Pemilik UMKM Indonesia**

Karakteristik:
- Mengelola usaha sendiri atau dengan tim kecil.
- Melakukan transaksi setiap hari.
- Tidak memiliki latar belakang akuntansi.
- Sering mencatat transaksi secara sederhana.
- Membutuhkan cara cepat untuk mengetahui kondisi keuangan usaha.
- Tidak ingin berhadapan dengan istilah akuntansi yang rumit.
- Membutuhkan informasi yang dapat membantu mengambil keputusan.

### Masalah Utama
User sering memiliki data transaksi, tetapi kesulitan menjawab:
- Berapa uang yang masuk?
- Berapa uang yang keluar?
- Berapa saldo usaha?
- Pengeluaran terbesar saya apa?
- Apakah kondisi keuangan usaha saya membaik?
- Ke mana uang usaha saya paling banyak pergi?
- Apa yang perlu saya perhatikan?

### Kebutuhan Utama
**Catat → Hitung → Pahami → Bertindak**

## 2. User Journey Utama

### Stage 1 — Awareness
User mengetahui Afin.ai dari media sosial, website, rekomendasi, komunitas UMKM, konten edukasi, atau search engine.

Kondisi user: “Selama ini saya mencatat transaksi, tetapi tidak benar-benar tahu kondisi keuangan usaha saya.”

Desired action: **Mencoba Afin.ai**.

### Stage 2 — Landing Page
User memahami value proposition, fitur, kemudahan penggunaan, keamanan data, dan fungsi AI.

Hero: **Jangan Cuma Catat Uang. Pahami Ke Mana Uang Anda Pergi.**

Desired action: **Mulai Kelola Keuangan dengan AI**.

### Stage 3 — Registration
User memilih Daftar, memasukkan email dan password, lalu diarahkan ke Dashboard setelah autentikasi berhasil.

### Stage 4 — Onboarding
Afin.ai menjelaskan secara singkat:
1. Mulai dengan mencatat transaksi.
2. Afin.ai menghitung kondisi keuangan.
3. AI membantu menjelaskan apa yang terjadi.

### Stage 5 — First Transaction
User memilih Tambah Transaksi dan mengisi:
- Jenis transaksi
- Nominal
- Kategori
- Deskripsi
- Tanggal

Contoh: Pemasukan Rp750.000, kategori Penjualan, deskripsi Penjualan hari ini.

### Stage 6 — First Value Moment
Setelah transaksi tersimpan, dashboard diperbarui. User melihat pemasukan, pengeluaran, saldo, dan arus kas bersih.

Ini adalah **First Value Moment**: user memahami bahwa pencatatan menghasilkan informasi yang berguna.

### Stage 7 — More Transactions
User mulai mencatat transaksi secara rutin dan melihat kategori pengeluaran, transaksi terbaru, serta arus kas.

### Stage 8 — Discovery
User mulai bertanya seperti:
- “Pengeluaran saya paling besar di mana?”
- “Bagaimana kondisi keuangan usaha saya?”

User membuka **AI Assistant**.

### Stage 9 — AI Assistant
User bertanya dengan bahasa sehari-hari. Afin.ai mengambil financial context user, calculation engine menghitung data, lalu Gemini menjelaskan hasilnya.

**AI tidak menggantikan calculation engine. AI menjelaskan data, bukan mengarang data.**

### Stage 10 — Insight
Contoh insight: “Bahan baku merupakan pengeluaran terbesar Anda bulan ini, yaitu sekitar 51% dari total pengeluaran.”

Kemudian AI dapat memberi tindakan sederhana, misalnya memeriksa harga pemasok dan volume pembelian.

### Stage 11 — Repeat Usage
User membentuk kebiasaan:
**Buka Afin.ai → Catat transaksi → Lihat dashboard → Tanya AI jika diperlukan → Ambil keputusan.**

### Stage 12 — Retention
Afin.ai digunakan untuk pencatatan harian, review mingguan/bulanan, memantau pengeluaran, cash flow, dan mencari insight.

## 3. Core User Loop

**TRANSAKSI → CATAT → HITUNG → LIHAT → TANYA → PAHAMI → BERTINDAK → CATAT LAGI**

## 4. User Journey Berdasarkan Tujuan

### Goal A — Mencatat transaksi
Landing → Register → Dashboard → Tambah Transaksi → Simpan → Transaction List

### Goal B — Mengetahui kondisi keuangan
Login → Dashboard → Income → Expense → Balance → Cash Flow

### Goal C — Menemukan pengeluaran terbesar
Login → Dashboard → Cash Flow → Expense Breakdown → Category → AI Assistant

### Goal D — Mendapatkan insight
Login → Dashboard → AI Assistant → Pertanyaan → Financial Context → Gemini → Insight → Action

## 5. Emotional Journey

**Bingung → Lebih terkontrol → Mulai memahami → Mendapat insight → Lebih percaya diri**

## 6. Product Success Moment

Afin.ai berhasil ketika user berpindah dari:
> “Saya punya banyak transaksi.”

menjadi:
> “Saya tahu apa yang sedang terjadi pada keuangan usaha saya.”

dan akhirnya:
> “Saya tahu apa yang perlu saya lakukan.”

## 7. Primary User Journey

**DISCOVER → TRY → RECORD → UNDERSTAND → ASK → INSIGHT → ACT → RETURN**
