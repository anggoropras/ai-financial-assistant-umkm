# AI Financial Assistant untuk UMKM

Prototype asisten keuangan sederhana untuk membantu pelaku UMKM memahami kondisi keuangan usaha.

## Fitur

- Input omzet, HPP, biaya operasional, dan biaya lain-lain.
- Perhitungan laba kotor, laba bersih, dan margin bersih.
- Visualisasi sederhana komposisi biaya.
- Insight otomatis berbasis aturan untuk membantu membaca kondisi keuangan.
- Berjalan langsung di browser tanpa database eksternal.

## Teknologi

- HTML5
- CSS3
- JavaScript (Vanilla)

## Menjalankan

Tidak membutuhkan backend atau instalasi dependency. Buka `index.html` di browser.

## Catatan

Versi saat ini adalah **prototype frontend**. Fitur AI generatif, database, autentikasi, dan integrasi API belum terhubung.
